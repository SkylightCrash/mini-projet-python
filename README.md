## 🎯 Présentation du projet

Ce projet a été réalisé dans le cadre d'une initiation algorithmique en **Python**. Il simule le système de gestion de notes d'une classe de 7 étudiants.

Le programme ne se contente pas de stocker des données : il les **analyse**, attribue des **mentions**, dresse des **statistiques globales** et **sauvegarde** automatiquement le tout dans un fichier de compte-rendu.

---

## ✨ Fonctionnalités implémentées

| Partie | Objectif | Statut |
| --- | --- | --- |
| **1** | 🗂️ Création et organisation des données (Listes & Dictionnaires) | ✅   |
| **2** | 🧮 Calcul des moyennes, mentions et recherche du meilleur élève | ✅   |
| **3** | 📈 Analyse globale (Moyenne de classe, taux de réussite) | ✅   |
| **4** | 💾 Exportation automatique des résultats (`resultats.txt`) | ✅   |
| **5** | 🔍 Moteur de recherche d'étudiant par prénom (Insensible à la casse) | ✅   |
| **6** | 🚀 **[BONUS]** Interface d'ajout interactif d'étudiants avec sécurité de saisie | ✅   |

---

## 🛠️ Comment utiliser ce programme ?

<details>
<summary><b>👉 Clique ici pour dérouler les instructions d'installation et d'exécution</b></summary>

<br>

1. **Cloner ou télécharger** ce dépôt sur votre machine locale.
2. Assurez-vous d'avoir Python 3 installé.
3. Ouvrez un terminal dans le dossier du projet.
4. Lancez le script avec la commande suivante :

```bash
python main.py
```

*(Remplacez `main.py` par le nom exact de votre fichier python).*

**Résultat attendu :** 
Le terminal affichera toutes les statistiques en direct, et un fichier texte nommé `resultats.txt` apparaîtra comme par magie dans votre dossier ! ✨

</details>

<details>
<summary><b>🎮 Comment tester le mode interactif (Bonus) ?</b></summary>

<br>

Pour tester la fonctionnalité d'ajout interactif (Partie 6), il vous suffit de décommenter la toute dernière ligne du script Python :

```python
# Enlevez le hashtag juste en dessous pour activer le mode interactif :
ajouter_etudiant()
```

Relancez le script, et le programme vous demandera de saisir un prénom et 3 notes comprises entre 0 et 20 !
